
# Favicon Builder

**Create favicons and app icons from a single image.**

Favicon Builder is a browser-based utility by Nicholas Van-Orton
(NVO987) that generates a downloadable package of website favicons,
platform icons, web app manifests, and integration files.

## Website

https://favicon.nvo987.us/

## Features

- Image input: PNG, JPEG, SVG, and WebP, subject to browser support.
- Drag-and-drop and file-picker upload.
- Multiple PNG icon sizes.
- ICO favicon generation.
- SVG favicon and Safari pinned-tab asset generation.
- Apple Touch Icons.
- Android and maskable app icons.
- Web app manifests.
- Microsoft tile assets and browser configuration.
- Open Graph preview image generation.
- HTML integration snippet and installation instructions.
- ZIP archive generation directly in the browser.

## Privacy

The application is designed to process the selected source image
locally in the browser. The image-generation workflow does not
intentionally upload the source image to the application server.

The application loads JSZip from a third-party CDN. As with any
externally hosted dependency, network requests may be made to that
provider when the page loads.

## Getting Started

1. Open https://favicon.nvo987.us/.
2. Select an image or drag it into the upload area.
3. Generate the icon package.
4. Extract the downloaded ZIP archive.
5. Copy the generated assets to your website's public directory.
6. Review and customize the generated HTML and manifest files.

## Requirements

- A modern web browser with HTML5 Canvas support.
- JavaScript enabled.
- Network access to load the JSZip dependency, unless it is hosted
  locally instead.
